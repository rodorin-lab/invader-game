## 🎮 **遊び方 — 超カンタン！** 🎮

### 📱 **スマホ**

```
┌─────────────────────────────────┐
│                                 │
│       🦋 グラムちゃん 👾        │
│                                 │
│    ╔═══════════════════════╗    │
│    ║  ▶ タップしてスタート ◀ ║    │
│    ╚═══════════════════════╝    │
│                                 │
│   👆       画面どこでも       👆  │
│   ←─── ドラッグで移動 ───→   │
│   🔥     オート連射で攻撃     🔥  │
│                                 │
│   画面を タップ → ボム！！💣    │
│                                 │
└─────────────────────────────────┘
```

| 操作 | なにが起こる？ |
|------|-------------|
| 👆 **画面をドラッグ** | 自機が高速移動！自動で撃ちまくり！ |
| 👊 **画面をタップ** | ボムが炸裂！画面中が大爆発！💣 |
| 🔄 **🔄ボタン** | オート連射ON/OFF（標準ONだから押さなくてOK） |
| 💣 **💣ボタン** | ボム発射（タップと同じ） |

### ⌨️ **PC（キーボード）**

| キー | 動作 |
|:---:|------|
| ⬅️ **← / A** | 左に移動！ |
| ➡️ **→ / D** | 右に移動！ |
| 🔫 **スペース** | 射撃＆スタート！ |
