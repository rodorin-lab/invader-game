## 🎮 ゲーム概要

クラシックインベーダーゲームを**全部盛り**で超絶進化！

- 🎨 **グラムちゃんカラー** — 紫×ピンクのネオン宇宙
- ⚡ **4種パワーアップ** — 拡散・シールド・高速・メガブラスト
- 👾 **ウェーブシステム** — 段階的に難易度上昇！
- 💀 **ボス戦** — 3ウェーブごとに巨大ボス登場
- 🌍 **英語/日本語切り替え** — ワンクリックで言語変更
- 📱 **スマホ対応** — タッチ＋スワイプ操作
- ✨ **ネオンエフェクト** — 発光・パーティクル・画面シェイク

## 🕹️ 遊び方

### ⌨️ PC（キーボード）

| キー | 動作 |
|------|------|
| ⬅️ **← / A** | 左に移動 |
| ➡️ **→ / D** | 右に移動 |
| 🔫 **スペース** | 射撃！ |
| 🔄 **スペース（ゲームオーバー時）** | リスタート |

### 📱 スマホ（タッチ）

| 操作 | 動作 |
|------|------|
| 👆 **画面左右ドラッグ** | 自機が追従して移動 |
| 👆 **🔥ボタン** | 射撃！ |
| 👆 **⬅️➡️ボタン** | 左右移動 |
| 👆 **画面タップ（メニュー時）** | ゲーム開始 / リスタート |

---

## 💎 パワーアップアイテム

敵を倒すと時々ドロップ！ゲットすると超強化！

| アイテム | 効果 | 持続時間 |
|----------|------|---------|
| 💫 **拡散ショット** | 弾が3方向に！範囲攻撃！ | 8秒 |
| 🛡️ **シールド** | 1回だけ被弾を防ぐ | 10秒 |
| ⚡ **高速連射** | 弾がめっちゃ速くなる！ | 8秒 |
| 💥 **メガブラスト** | 巨大弾で敵を貫通破壊！ | 6秒 |

## 👾 ゲームシステム

### 📈 ウェーブ進行

| Wave | 敵の数 | スピード | 備考 |
|------|--------|---------|------|
| 1 | 15 | 普通 | チュートリアル |
| 2 | 20 | やや速い | |
| 3 | 25 | 速い | **⚠️ ボス戦！** |
| 4+ | 増加 | どんどん速く | |

### 💯 スコアシステム

| アクション | スコア |
|-----------|--------|
| 🦑 イカを倒す | 10pt |
| 🦀 カニを倒す | 20pt |
| 🐙 タコを倒す | 30pt |
| 💥 ボスにダメージ | 50pt/回 |
| 👾 ボス撃破 | **+1000pt！** |
| 🔥 コンボ倍率 | 5連続で+50%！ |

### ❤️ ライフ

- 初期ライフ：**3ハート**
- 被弾で-1（シールドがあれば消費して回避）
- 0になるとゲームオーバー
